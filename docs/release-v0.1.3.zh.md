# COBOT MAGIC Workbench v0.1.3 版本说明

连接页四角分别显示 LE 左执行臂、RE 右执行臂、LT 左示教臂和 RT 右示教臂。俯视图居中，点击臂卡标题、图上标记或底盘可查看详情。界面分别显示设备反馈和当前可申请的操作。

- 从 RE 卡片申请电脑接管（CAN / MOVEJ）或六关节电机失能。连接页底栏已移除重复的接管按钮，“更多模式”里的重复失能按钮已移除。右执行臂的诊断、原厂高跟随、待机和受支撑复位均标出 RE。模式请求须指定设备，按钮显示与提交使用同一组准入检查。
- 运动测试中的“全部 CAN/MOVEJ 臂六零位”在点击时冻结已登记的目标臂清单。执行器复核实际模式、通道身份、反馈、六个电机使能、STOP 和控制权，再逐臂执行六关节零位轨迹。每条入选臂仍有运行器原有的模式握手。夹爪保持当前开度。
- 顶部“停止新目标”和部署页“停止运行”共用软件停止通路。“结束并保存”按采集片段收尾，DAgger 介入按模型任务身份交接。清除停止锁存统一在全局 STOP 提示中操作。
- 显式重连会重新核对原 U 盘的挂载身份和占用。工作台提示右侧共享反馈失效及新增总线错误。
- 公开页面支持只读查看四臂布局和设备说明。在线俯视图由浏览器从固定的 AgileX 上游资产渲染，离线或 WebGL 不可用时显示位置示意。Windows SDK 提供离线工作台和已授权 SSH 连接入口。

**实机范围。** 当前卡片接入 RE 的原有电脑接管和失能接口，是否可点击以实际反馈为准。其余三臂的实体模式写入、主从对遥操作和自由拖动仍待独立接入与验证。本次验收范围为软件、页面、真实只读回传及离线接口，四臂物理切换与回零未做实机验收。
