# Bilingual operator workbench preview

An isolated design study of six workbench views. English action labels lead; Chinese translations sit below. Playback and inspection are interactive. Device status, draft edits and the DAgger rehearsal never invoke a live controller.

Serve the repository root over HTTP and open `/previews/workbench/`. Run `python previews/workbench/export_preview.py Review.html` with a new destination filename to create an offline review copy.

Images and joint data come from the approved demo in `site/assets/demo/`. Camera views are cropped for display. The source trial stopped on an evidence-queue error and task success was not scored. Credit and license details are available at the bottom of the media views. The visual reference is the November 18 project-page style guide.
